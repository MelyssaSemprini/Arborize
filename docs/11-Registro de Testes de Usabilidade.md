# Registro de Testes de Usabilidade

Após realizar os testes de usabilidade, obtém-se um relatório a partir das análises realizadas. O Registro de Testes de Usabilidade é um relatório que contém as evidências dos testes e relatos dos usuários participantes, baseado no Plano de Testes de Usabilidade desenvolvido para os casos de uso desta etapa.

|Campos | Análise do Participante|
|------------|--------------------|
|Facilitador |	Equipe |
|Participante |	Melyssa |
|Contexto do Teste |	Avaliação Tela de Login|
|Observações | Ajustar responsividade	|
|Primeiras Impressões |	Tela para que o usuário efetue login|
|Usabilidade | Página com o cabeçalho com nome que se refere ao uso da página. Campos com as informações necessárias para realizar o login no site	|
|Feedback do Participante |	Interessante para que o usuário acesse o conteúdo que ele posta e árvores cadastradas|
|Facilidade de Acesso |	De fácil de acesso, disponível na tela de "Home" após clicar no botão de "Entrar" |
|Design e Layout |	Design simples e layout responsivo |
|Erro na Funcionalidade |	Responsividade do layout em telas maiores o botão "voltar" responsável por voltar a tela de "Home", não aparece|
|Conclusões | Fora a responsividade a página está funcionando como o esperado|
|Ações Recomendadas |	Sugestão de ajustar a responsividade do botão para diferentes tamanhos de tela|
